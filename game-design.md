# Геймплейные системы
### ❌Прогрессия
Есть главная цель, от нее идут майлстоуны.
В майлстоуне каждом есть этапы.

Этапы и майлстоуны требуют ресурсов для своего открытия. Каждый этап и майлстоун открывает возможность крафтить/добывать ресурсы, которые обязательно нужны для открытия следующих этапов.

В прогрессии может открываться:
- Новое снаряжение для боевки
- Новые постройки и улучшения старых построек
- Quality of Life фичи

### ❌Экономика
Синки ресурсов:
- Крафтовые цепочки (например 3 руды превращаются в 2 слитка)
- Снаряжение для боевки

Источники ресурсов:
- Боевка: Мобы и боссы
- Месторождения ресурсов

### Боевка
Боевка - это точка, куда игрок сливает свои топовые ресурсы.
Из этих топовых ресурсов игрок крафтит себе:
- снаряжение - броня для защиты от атак мобов
- оружие - для сражения с мобами в ближнем бою
- заклинания - для сражения с мобами в дальнем бою

#### ✅Мобы
Мобы - источники крутых ресурсов. Игрок их может гриндить.

Мобы могут спавнится 2мя способами:
- Скриптованные - геймдиз поставил точку спавна и триггер, мобы по триггеру заспавнились один раз
- Постоянные - геймдиз поставил точку спавна и кулдаун между спавном мобов, мобы по истечению кулдауна заспавнились. Если старые мобы этой точки живы - новые не спавнятся.

Таблица мобов:

| zombie   | Зомби  | Обычный рядовой моб. Должно быть приятно его превосходить и лупить мечом. | 100% Кость<br>50% - Душа |


#### ✅ Механики боевки
**Деш с кулдауном.** 
Игрок на кнопку key.dash быстро дешится в направлении движения.

**Спринт.**
При активном спринте игрок ускоренно перемещается.
Спринт аткивен при удержании кнопки key.sprint

**Атака оружием ближнего боя**.
При нажатии кнопки key.main_action персонаж совершает атаку ближнего боя выбранным оружием.
При удержании кнопки key.main_action персонаж совершает атаки ближнего боя подряд.

У разных оружий ближнего боя могут быть разные комбо. Например:
 - 1 атака - 100% урона
 - 2 атака - 110% урона
 - 3 атака - завершающая, более медленная, 150% урона

### ✅ Персонаж игрока
#### ✅ Управление
Игрок управляет персонажем.

У персонажа есть 4 направления: юг, север, запад, восток. Спрайты персонажа на запад и восток одинаковые.

Персонаж может применять инструменты (реф. Stardew Valley x Terraria). Нужны анимации персонажа:
- swing_tool - ударил сверху вниз, для инструментов
- swing_sword - ударил слева направо, для оружия

#### ✅ Добыча ресурсов
По карте мира раскиданы точки спавна разных ресурсов. 

Месторождения руды геймдиз расставляет на карте вручную.



Как выглядит добыча ресурса:
1. Игрок подходит к месторождению ресурса
2. Игрок нажимает кнопку key.interact
3. Персонаж игрока автоматически встает у месторождения
4. Когда игрок нажимает key.interact:
	1. Персонаж бьет месторождение
	2. Игра заполняет прогресс бар добычи месторождения
5. Когда прогресс бар добычи заполнен до конца:
	1. Прогресс бар добычи обнуляется
	2. Рядом с месторождением выпадает ресурс

#### ✅ Месторождения ресурсов
Нужно сделать такие месторождения руды (добываются киркой):
- Железо - при добыче выпадает Железная руда
- Уголь - при добыче выпадает Уголь

Нужно сделать такие месторождения древесины (добываются топором):
- Маленькое дерево - при добыче выпадает палка
- Большое дерево - при добыче выпадает древесина
#### ✅ Добыча предмета руками
Игрок может добывать некоторые объекты без инструментов - руками.

Флоу такой:
1. Игрок подходит к объекту
2. Игра показывает клавишу key.interact
3. Игрок удерживает кнопку key.interact
4. Персонаж игрока автоматически встает у объекта
5. Заполняется прогресс бар добычи предмета
6. Когда прогресс бар добычи заполнен до конца - объект удаляется, а на землю падает предмет

Если у объекта заложено несколько предметов внутри, то после добычи не-последнего предмета - объект не удаляется.

Нужно сделать такие объекты:
- Камень с мечом. При добыче из него выпадает меч.
- Ящик с инструментами. При добыче из него выпадает кирка
- Дерево с застрявшим топором. При добыче из него выпадает топор и само дерево становится обычным большим деревом.
#### ✅ Подбор ресурсов
В небольшом радиусе вокруг персонажа все выпавшие на землю предметы притягиваются к персонажу.

Когда предмет коснулся персонажа:
- Предмет пропадает с земли
- Предмет начисляется игроку в инвентарь

#### ✅ Инструменты

В начале игры у игрока в инвентаре есть:
- Меч - для атаки мобов
- Кирка - для добычи рудных месторождения
- Топор - для добычи деревьев

### ✅ Строительство
#### ✅ Алтарь
Алтарь - уникальная постройка, которую можно прокачивать по ходу игры новыми пристройками.

**Механика - Крафт на алтаре.**
Игрок выкладывает нужные предметы для ритуала на алтарь.

Когда все предметы выложены на алтарь - игра показывает прозрачную картинку предмета, который должен получиться

Игрок начинает крафт клавишей key.interact.

После начала крафта алтарь по очереди начинает засасывать все предметы в центр.

Получившийся предмет появляется в центре алтаря. 

У крафта на алтаре прикольные анимации, всякие спецэффекты. Крафт на алтаре должен ощущаться как что-то значимое.

Рецепты алтаря:

| ---------------- | ------------------------------ |

Если в печи еще есть энергия на плавку предметов, но нет самих предметов - то энергия не расходуется.

#### ✅ Строительство

Поставить площадку для строительства:
1. Когда игрок выбирает на тулбаре не-автоматическую постройку:
	1. Игрок переходит в режим строительства
	2. Силуэт постройки цепляется к курсору игрока
2. Игрок нажимает key.build
3. На выбранном месте размещается площадка для строительства

Игрок может разместить несколько площадок для строительства, не выходя из режима строительства.

Игрок не может размещать постройки на:
- Других постройках
- Площадках для строительства
- Ячейках, занятых месторождениями
- Ячейках, занятых мобами

Построить не-автоматическую постройку:
1. Персонаж подходит к площадке для строительства
2. Игра показывает key.interact и кол-во вложенных и необходимых ресурсов
3. Игрок нажимает key.interact
4. Персонаж стучит молотком по постройке
5. Игра заполняет прогресс-бар строительства
6. После заполнения прогресс-бара строительства игра списывает с игрока нужный ресурс
7. Если нужны еще ресурсы, то игра обнуляет прогресс бар
8. Если в постройку вложены все необходимые ресурсы, то площадка для строительства превращается в постройку

Если у игрока не хватает ресурсов для строительства, то игра показывает плашку с крестиком.



#### ✅ Крафт
Игрок с помощью построек может крафтить разные материалы.

Всего есть 2 вида крафтов:
1. Ручной - игрок должен сам стоять у постройки и крафтить предмет
2. Автоматический - крафт происходит автоматически при наличии в инвентаре постройки нужных ресурсов

Флоу ручного крафта такой:
1. Игрок на экране постройки выбирает материал, который хочет скрафтить
2. Игра закрывает экран постройки
3. Игрок удерживает клавишу key.craft
4. Игра заполняет прогресс-бар крафта
5. Когда прогресс-бар крафта заполнен:
	1. Материал падает рядом с постройкой
	2. Прогресс-бар обнуляется
#### ✅ Режим сноса построек
Игрок может снести постройку или площадку для строительства, которую сам построил.

Флоу такой:
1. Игрок переходит в режим сноса клавишей key.destroy
2. Когда игрок наводит клавишу на постройку - она выделяется красным
3. Когда игрок жмет клавишу key.main_action:
	1. Постройка удаляется
	2. Игра начисляет игроку ресурсы

При сносе постройки или площадки для строительства использованные ресурсы сразу попадают в инвентарь игрока.

Игрок может перейти в экран построек клавишей key.build_screen.

- Все разблокированные и доступные игроку постройки

Подобранные предметы не попадают в слот с ярлыком. Если игрок кладет в этот слот предмет мышкой, ярлык пропадает.

### Механики

#### Алтарь (крафт)
Алтарь - ключевая механика прогрессии. 
Алтарь - это структура, которую игрок усложняет элементами на протяжении всей игры. Алтарь нужно строить из элементов определенным образом.

#### Культист
Их можно прокачивать
Культисты - это основной источник мемов. Они постоянно угарно страдают.
Их можно перемещать между постройками свободно. 

потенциальные рефы:
- жители из майнкрафта - профессии
- graveyard keeper зомби
- АНТИРЕФ - rimworld

**Рабочий вариант (07.10).** Культист - ресурс по механике, личность по подаче:
- перки прокачиваются сразу у всех культистов, личной прокачки нет
- на культистов можно надевать снаряжение, которое их усиливает, и снимать его
- жертва на алтаре превращает культиста во что-то другое (дух, элементаль и т.п.) или делает его ингредиентом рецепта (оружие, броня и т.п.)
- имя культиста прописывается в скрафченной из него вещи

Снаряжение культиста при его жертве тоже удаляется.

Способы получить культистов:
- Завербовать побежденных врагов-людей
- Спасти в мире своих старых последователей
- Бесконечный источник - вербовка мирных жителей в городе (рейты ограничены)
