# Фейкшоты — 29.09.2026

Пять визуальных предложений по запросу пользователя. Созданы встроенным image_gen; это концепты, не скриншоты работающей игры. Выбор направления пока не сделан.

Изучены art-direction.md, concept-doc.md, design-doc.md (пустой), architecture.md и roadmap.md, а также три присланных референса и UI-референс из attachments. Активный vault Obsidian — эта папка design-doc.

Общая сцена: лесная мастерская, добыча → печь → механическая обработка → хранение, алхимический аппарат, персонаж и составной алтарь. Конкретные машины, предметы и HUD — визуальные допущения для сравнения, не утверждённые рецепты или игровые системы.

Визуально проверены все пять результатов. Есть вариации композиции; это сравнение направлений, не строго одинаковая карта. №4 крупнее по формам, но генерация не гарантирует единую нативную пиксельную сетку. Для игровых ассетов после выбора потребуется отдельная нормализация масштаба пикселя.
