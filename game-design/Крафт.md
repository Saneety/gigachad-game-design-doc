# Описание
Игрок **крафтит** разные материалы с помощью построек.

Всего есть 2 вида крафтов:
1. Ручной - игрок должен сам стоять у постройки и крафтить предмет
2. Автоматический - постройка сама крафтит предмет из ресурсов, которые берет с конвейерных лент

Рецепты построек лежат в [[configs#Постройки]].

# Цели
Что даст игроку:
- Крафт - базовая механика жанра, мастхэв

# Логика фичей
## Скрафтить материал вручную
Флоу такой:
1. Игрок открывает экран постройки клавишей key.interact
2. Игрок на экране постройки выбирает материал, который хочет скрафтить
3. Игра закрывает экран постройки
4. Игрок удерживает key.craft
5. Игра заполняет прогресс бар крафта
6. Когда прогресс бар крафта заполнен:
	1. Игра списывает ресурсы рецепта из инвентаря игрока
	2. Материал падает рядом с постройкой
	3. Игра обнуляет прогресс бар

### Нюансы
Если игрок не выбрал рецепт, игра показывает подсказку «Выбери рецепт: [key.interact]».

Если у игрока не хватает ресурса, игра показывает подсказку «Нужно: [ресурс]».

## Постройка крафтит материал автоматически
Постройка берет ресурсы рецепта с конвейерных лент и крафтит материал сама, игроку не надо стоять рядом. Как постройка крепится к конвейерам, лежит в [[Конвейеры]].
