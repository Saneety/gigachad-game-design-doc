# Описание
Предметы, которые выпали на землю, игрок **подбирает** сам собой: они притягиваются к персонажу.

# Цели
Что даст игроку:
- Игроку не надо кликать по каждому предмету: добыча идет без лишних действий

# Логика фичей
## Подобрать предмет
В небольшом радиусе вокруг персонажа все выпавшие на землю предметы притягиваются к персонажу.

Когда предмет коснулся персонажа:
- Предмет пропадает с земли
- Игра начисляет предмет игроку в инвентарь

### Нюансы
Если в инвентаре нет места, предмет остается на земле.
