# Описание
Игрок добывает **ресурсы** из **месторождений**. По карте мира раскиданы точки спавна разных ресурсов.

Месторождения руды геймдизайнер расставляет на карте вручную. Месторождения бесконечные.

Месторождения, их ресурсы и сколько ударов нужно на добычу, лежат в [[configs#Месторождения]].

# Цели
Что даст игроку:
- Добыча - источник ресурсов
- Добыча дает иммерсивность

Что даст геймдизайну:
- Ручная добыча контрастирует с автоматизацией

# Логика фичей
## Добыть ресурс
Флоу такой:
1. Игрок подходит к месторождению ресурса
2. Игрок удерживает key.interact
3. Персонаж игрока автоматически встает у месторождения
4. Пока игрок удерживает key.interact, персонаж бьет месторождение без остановки. Каждый удар заполняет прогресс бар добычи месторождения на шаг
5. Когда прогресс бар добычи заполнен до конца:
	1. Игра обнуляет прогресс бар добычи
	2. Рядом с месторождением выпадает ресурс

### Нюансы
Когда игрок отпускает key.interact, персонаж доигрывает начатый удар и останавливается.

Если игрок коротко нажал key.interact, персонаж бьет месторождение 1 раз.

Игрок добывает месторождение, только если в тулбаре выбран нужный инструмент. Какой инструмент нужен месторождению, лежит в [[configs#Месторождения]].

Если в тулбаре выбран не тот инструмент, игра показывает подсказку "Нужно: [инструмент]", например "Нужно: Кирка".
