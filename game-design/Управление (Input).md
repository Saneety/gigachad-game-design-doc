# Описание
Игрок управляет игрой **хоткеями**. На отдельном экране в настройках игрок настраивает хоткеи по своему усмотрению.

Хоткеи одной **группы сочетания** могут стоять на одной клавише. Исключение - группа "Общая": в ней хоткей стоит по умолчанию, и ее хоткеи друг с другом не сочетаются.

# Цели
Что даст игроку:
- Базовый QoL: игрок настраивает хоткеи под себя и играет как ему комфортно

# Логика фичей
## Настроить хоткей
На экране в настройках игрок назначает хоткею другую клавишу.

Флоу такой:
1. Игрок кликает по хоткею
2. Игра ждет нажатия клавиши
3. Игрок нажимает новую клавишу
4. Игра назначает хоткею эту клавишу

### Нюансы
Если клавиша уже назначена другому хоткею, игра показывает модалку "Клавиша уже назначена для [хоткей]. Заменить?".

Когда игрок подтверждает замену:
- Игра назначает клавишу новому хоткею
- Игра возвращает замененному хоткею клавишу по умолчанию

Когда игрок отказывается, игра ничего не меняет.

Игра НЕ показывает модалку, если оба хоткея в одной группе сочетания, кроме "Общей". Тогда игра назначает клавишу, и оба хоткея работают на ней.

Если клавиша по умолчанию у замененного хоткея занята, хоткей остается без клавиши. Игра показывает у него предупреждение "Хоткей не назначен".

## Сбросить все хоткеи
Игрок нажимает кнопку "По умолчанию", и игра возвращает всем хоткеям клавиши по умолчанию.
