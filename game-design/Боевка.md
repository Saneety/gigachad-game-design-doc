# Описание
**Боевка** - точка, куда игрок сливает свои топовые ресурсы. Из топовых ресурсов игрок крафтит себе:
- **Тела** - для защиты от атак мобов
- **Оружие** - для сражения с мобами в ближнем бою

# Цели
Что даст игроку:
- Боевка раскрывает фантазию мести
- Игрок лутает ресурсы с мобов

Что даст геймдизайну:
- Игрок утилизирует ресурсы экономики в боевке
