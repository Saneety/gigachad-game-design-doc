# Описание
Игрок добывает некоторые объекты без инструментов - **руками**. Из объекта выпадает **предмет**.

Какие предметы выпадают из объектов и сколько держать key.interact на один предмет, лежит в [[configs#Добыча руками]].

# Цели
Что даст игроку:
- Добыча руками дает сценарную иммерсивность

Что даст геймдизайну:
- Онбординг игрока: игра выдает ему первые инструменты

# Логика фичей
## Добыть предмет руками
Флоу такой:
1. Игрок подходит к объекту
2. Игра показывает клавишу key.interact
3. Игрок удерживает key.interact
4. Персонаж игрока автоматически встает у объекта
5. Игра заполняет прогресс бар добычи предмета
6. Когда прогресс бар добычи заполнен до конца, игра удаляет объект, а на землю падает предмет

### Нюансы
Если игрок отпустил key.interact, прогресс добычи остается.

Если в объекте лежит несколько предметов, после добычи не последнего предмета игра НЕ удаляет объект. Например, из ящика с инструментами по очереди выпадают кирка и лопата.

Дерево с застрявшим топором после добычи НЕ исчезает, а становится обычным большим деревом.
