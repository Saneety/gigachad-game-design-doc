# Описание
Игрок строит **постройки** в 2 шага: ставит **площадку для строительства** и вкладывает в нее ресурсы. Какие постройки есть, лежит в [[Постройки]].

# Цели
Что даст игроку:
- Строительство - база жанра

# Логика фичей
## Поставить площадку для строительства
Флоу такой:
1. Когда игрок выбирает на тулбаре не-автоматическую постройку:
	1. Игрок переходит в режим строительства
	2. Силуэт постройки цепляется к курсору игрока
2. Игрок нажимает key.build
3. Игра размещает площадку для строительства на выбранном месте

### Нюансы
Не-автоматические постройки - все постройки, кроме конвейерной ленты, объединителя и разъединителя. Их игра ставит сразу, без площадки для строительства, это в [[Конвейеры#Проложить конвейер]].

Игрок может разместить несколько площадок для строительства, не выходя из режима строительства.

Игрок НЕ может размещать постройки на:
- Других постройках
- Площадках для строительства
- Ячейках, занятых месторождениями
- Ячейках, занятых мобами

## Построить не-автоматическую постройку
Флоу такой:
1. Персонаж подходит к площадке для строительства
2. Игра показывает key.interact и количество вложенных и необходимых ресурсов
3. Игрок нажимает key.interact
4. Персонаж стучит молотком по постройке
5. Игра заполняет прогресс бар строительства
6. Когда прогресс бар заполнен, игра списывает с игрока нужный ресурс
7. Если нужны еще ресурсы, игра обнуляет прогресс бар
8. Когда в постройку вложены все необходимые ресурсы, площадка для строительства превращается в постройку

### Нюансы
Если у игрока не хватает ресурсов для строительства, игра показывает плашку с крестиком.
