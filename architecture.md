## Описание архитектуры
Data-Driven Layered Architecture

Архитектура состоит из слоев:
 - Data - конфиги, статичные данные, формулы и значения
 - Game Logic - логика игры, код, механики, алгоритмы
 - View - отображение логики
 - Input - то, что обрабатывает действия игрока и передает в логику
 - UI - по сути отдельная View для интерфейса. Читает состояние игры и отправляет команды через controllers/actions.
 - Save/Load - сохраняет состояние симуляции, а не GameObject'ы и визуальный мусор.
 - Utils - все вспомогательное - апишки, локализация, аналитика и тп

НЕЛЬЗЯ:
- Хардкодить контент. Вместо этого нужно делать под каждый вид контента свою структуру конфигов.
- Бесконтрольное создавать новые системы, которые дублируют уже существующие.
